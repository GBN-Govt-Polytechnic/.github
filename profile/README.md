## Why this organization exists

This is the official GitHub home of **GBN Govt. Polytechnic, Nilokheri**. We use it to build, maintain and preserve the institute's software — from the college website to internal tools and legacy code.

## <img src="assets/git-pull-request.svg" width="18" height="18" alt="Pull request" /> Contributing

**We are actively looking for contributors.** Students, alumni, faculty and external developers are all welcome — whether you're fixing a bug, improving an existing tool, building something new, or helping modernise legacy code.

How to get involved:

1. **Reach out** to the project lead (below) to get access to the relevant repository.
2. **Pick something** — an open issue, a bug you found, or an idea of your own.
3. **Open a pull request** — fork, branch, commit, and describe what you changed.
4. **Review & merge** — we'll review, help you polish it, and get it merged.

No contribution is too small. If you're learning, this is a real codebase used by 600+ students, faculty and staff — a great place to grow.
